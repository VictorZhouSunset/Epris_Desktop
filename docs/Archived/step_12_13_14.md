# Step 12: Add an user resource upload section

User can upload their own resources (images, videos, audio, script files etc.) to be used in the video. The uploaded resources should be stored in a project specific public/ folder. The user should be able to rename, delete the resources. In the next step, we will add the possiblity of multiple projects, so the resources should be stored in a project specific folder.

# Step 13: Add "Project" Side Panel (left) and "Parameters" Side Panel (right)

Add a side panel to the application that will allow the user to create, delete, and switch between projects. Each project will have its own set of resources and parameters.

By settings, I mean there will be a right side panel that will allow the user to set the parameters for the video (specifically: width and height of the video and duration. I am worried about if the fps is mutable, there might be confusions in certain cases, so right now I suggest we fix the fps to 30, if you think a mutable fps can be handled well, let me know). It should only take the upper part of the right panel, the lower part will be used for something else later. For the width and height, I suggest we can have a quick selection of common ratios with demonstrative icons (buttons), and below that, a custom input for width and height. The resolution should be determined at the export stage. The export duration should match that shown on the UI here. The duration should be in seconds.

Use any open source voice to text model (small is preferred), I would prefer it to be downloaded and configured in the first run wizard as an optional component (when not present, the voice to text button will be disabled---greyed out).

# V0.5 Updater + Sandbox Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add an auto-update distribution loop (0.5.0 → 0.5.1 via GitHub Releases) and tighten AI/workspace sandbox boundaries to the active `projectRoot`, matching `docs/epris_v_0.5.md`.

**Architecture:** Use Tauri v2 updater plugin (signed updates + `latest.json`) with a small UI state machine in Settings. For sandboxing, add a Rust path-guard module (canonicalize + allow/deny patterns) and run post-provider audits to detect forbidden path modifications.

**Tech Stack:** Tauri v2 (Rust), Vite + React + TS, GitHub Actions, Tauri updater signing.
